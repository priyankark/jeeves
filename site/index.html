THE STORY BEHIND THE NAME

Why Jeeves?

In P. G. Wodehouse’s comic stories, Bertie Wooster has a talent for getting into trouble. His valet, Jeeves, has a talent for getting him out of it. Calm, resourceful, and usually several steps ahead, he is the person you want around when a simple plan gets complicated.

Before you download

What does it cost?

The app is free and open source under Apache 2.0. The built-in example needs no API key. Live runs use the AI services you connect, which may charge for usage.

Which AI services can I use?

Agent steps can use OpenAI, Codex CLI, OpenRouter, or a local model. Live Jev decisions need a TypeSafe key. The welcome screen helps you save and test each connection, and you can skip setup and return later. Browser tasks also need Chrome.

How ready is it?

Jeeves is an early desktop preview. Start with a small task and review the result. Browser tasks depend on the websites they visit and can fail when a page changes. If something breaks, tell us on GitHub.

Does every workflow need Jev?

No. Writing, research, and browser steps can use your chosen AI service. Add a Jev decision when different answers should lead to different steps, such as sorting urgent and routine requests. Human input is a separate step that waits for your answer.

Where does my data go?

Your workspace and run history stay on your computer. Cloud AI steps send task context to the service you connect. You can choose a local model for agent steps. Browser tasks visit websites in a separate Chrome session.

Will it place orders or publish things for me?

The browser stops for manual review before checkout, payments, messages, or publishing. Other workflow integrations have their own configured actions, which you can inspect before running.
