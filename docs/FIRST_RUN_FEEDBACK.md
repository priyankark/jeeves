# First ten minutes with Jeeves

We want to know whether Jeeves makes sense before anyone explains it to you. Start at [getjeeves.app](https://getjeeves.app/). Use harmless sample notes for this exercise.

1. Explain what you think Jeeves does and which download you would choose.
2. Install it and run the built-in example without connecting an AI service.
3. Find the result and explain whether it was generated from your input or prepared sample data.
4. Open the run, inspect a step, and find how to make the panel larger.
5. If you want to try your own notes, find where to connect an AI service. Live providers may charge for use; connecting one is optional for this exercise.

Then [tell us how it went](https://github.com/priyankark/jeeves/issues/new?template=first_run.yml). Where did you hesitate? What did you expect? Would you use it for a real task?

## For a moderated session

Recruit a mix of people who use AI frequently and people who mainly use ordinary productivity apps. Include Mac and Windows users if available. Ask permission before recording. Let participants work without coaching; write down each point where they need help. Do not ask for keys or record passwords.

Use a simple record for each consenting participant:

| Observation                           | Record   |
| ------------------------------------- | -------- |
| Platform and app version              |          |
| Their description of Jeeves           |          |
| Chose the correct installer unaided   | Yes / No |
| Installed and opened it unaided       | Yes / No |
| Completed the example                 | Yes / No |
| Understood sample data versus live AI | Yes / No |
| Found the result and inspector        | Yes / No |
| Point where help was needed           |          |
| Their own words about the experience  |          |
| Follow-up issue                       |          |

Record real outcomes, including failures. Do not count automated or agent-operated sessions as external participants. Findings are not representative statistics; use them to identify specific problems to fix.
